# 🧠 Flappy Bird AI using Neuroevolution

This project explores how intelligent behavior can emerge through evolutionary learning by building an AI agent that learns to play *Flappy Bird* without any predefined rules or labeled data. The system combines a lightweight neural network with a genetic algorithm to iteratively improve performance over successive generations.

---

## 🚀 Project Overview

The objective of this project is to design and implement an autonomous agent capable of learning optimal gameplay strategies through simulation and natural selection. Each agent (bird) is controlled by a neural network, and a population of these agents evolves over time based on their in-game performance.

Rather than relying on traditional supervised learning or backpropagation, this project applies **neuroevolution**, allowing the model to learn purely from interaction with the environment.

---

## 🕹️ System Architecture

### Neural Network Controller

Each bird is powered by a simple feedforward neural network with:

- **Input Features:**
  - Bird’s vertical position  
  - Distance to the top pipe  
  - Distance to the bottom pipe  

- **Output:**
  - A single scalar value representing the decision to **jump** or **not jump**

The network computes a weighted sum of inputs, adds a bias term, and passes the result through a **tanh activation function** to produce a normalized output.

**Decision Rule:**
- Output > 0.5 → Jump  
- Otherwise → No action  

This minimal architecture keeps the model efficient while still enabling meaningful learning behavior.

---

## 🧬 Learning Approach: Genetic Algorithm

The model is trained using an evolutionary strategy rather than gradient-based optimization.

### Training Pipeline

1. **Initialization**  
   A population of agents is created with randomly assigned weights and biases.

2. **Evaluation (Fitness Function)**  
   Each agent plays the game independently. Fitness is determined by survival time or progress through obstacles.

3. **Selection**  
   Top-performing agents are selected based on fitness scores.

4. **Crossover**  
   New agents are generated by combining parameters from selected high-performing agents.

5. **Mutation**  
   Small random changes are introduced to weights and biases to maintain diversity and encourage exploration.

6. **Iteration**  
   This process is repeated over multiple generations, leading to progressively improved performance.

## 📈 Results & Observations

- **Initial generations:** Agents exhibit random, uncoordinated behavior  
- **Intermediate stages:** Agents begin to learn timing and obstacle avoidance  
- **Advanced generations:** Agents demonstrate consistent, near-optimal gameplay  

The system successfully learns effective strategies without explicit programming, showcasing the power of evolutionary learning.
